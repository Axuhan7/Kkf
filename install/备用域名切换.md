# 备用域名 + 接入链接全套切换说明（Kkf / 宝塔）

> 适用：主域名被微信/运营商/浏览器拦截后，用备用域名继续接待。  
> 配套：`install/安装说明.md`、`install/配置顺序.md`  
> 更新：2026-11-27（Asia/Shanghai）

下文用占位符，请自行替换：

| 占位 | 含义 | 示例 |
|------|------|------|
| `主域名` | 当前正在用的客服域名 | `kf.example.com` |
| `备用域名` | 新准备的干净域名 | `chat.example.net` |
| `项目目录` | 服务器上的源码根目录 | `/www/wwwroot/kf.example.com` |
| `商户ID` | `business_id` | `1` |

**原则：两个域名指向同一套代码、同一个数据库，不要复制两份程序。**

---

## 0. 先想清楚：三种用法

| 模式 | 什么时候用 | 做什么 |
|------|------------|--------|
| **A. 双域并存（推荐日常）** | 主域还能用，但怕被拦 | 备用域先加好；对外投放用备用域；后台可仍用主域 |
| **B. 全面切备用** | 主域已被拦/打不开 | `.env`、入口/落地域、推送、所有接入链接都改备用域 |
| **C. 再换第三域** | 备用域也被拦 | 重复本流程，换更新域名 |

日常建议：**用户侧链接永远优先用备用域**；主域留给自己登录后台。

---

## 1. 选域名与解析

### 1.1 域名建议

- 尽量与主域 **不同注册商 / 不同后缀**（如主域 `.com`，备用 `.net` / `.top`）
- 新注册、历史干净，避免被多次举报过的域名
- 不要用纯 IP 当客服入口（微信里更容易异常）

### 1.2 DNS 解析

在备用域名的 DNS 控制台添加：

| 类型 | 主机记录 | 记录值 |
|------|----------|--------|
| A | `@` 或 `chat` 等 | 服务器公网 IP（与主站相同） |

可选推送子域（方案 B）：

| 类型 | 主机记录 | 记录值 |
|------|----------|--------|
| A | `ws` | 同一服务器 IP |

解析生效后再继续（可用 `ping 备用域名` 看是否到你的 IP）。

## 2. 宝塔添加备用站点

1. 登录宝塔 → **网站 → 添加站点**
2. 域名填：`备用域名`（不要带 `https://`）
3. **根目录必须与主站相同**，例如：

```text
/www/wwwroot/kf.example.com/public
```

不要新建空目录，也不要再拷一份源码。

4. PHP 版本选 **7.4**
5. 数据库：选「不创建」（库已存在）
6. 提交后进入站点设置：
   - **SSL**：申请 Let’s Encrypt，开启「强制 HTTPS」
   - **伪静态**：与主站相同（thinkphp 规则）
   - **配置文件**：同样禁止访问源码目录，例如：

```nginx
location ~* ^/(runtime|application|config|install|vendor|thinkphp)/ {
    deny all;
}
```

7. 浏览器打开：

```text
https://备用域名/
```

能出首页再往下做。

### 2.1 防火墙

- 已放行 `80` / `443` 即可  
- 方案 A 仍需放行 `2081`  
- **`2082` 不要对公网开放**

---

## 3. 客服后台改「入口域名 / 落地域名」

路径：

**客服后台登录 → 设置（或系统设置 / 通用设置）→ 入口域名、落地域名**

对应页面字段（`setup`）：

| 字段 | 填写 | 作用 |
|------|------|------|
| **入口域名** `domain_entry` | `https://备用域名` | 接入方法页生成的链接、公众号链接等对外入口 |
| **落地域名** `domain_landing` | `https://备用域名` | 用户点开后真正打开对话页的域名 |

注意：

- 必须带协议，**无末尾斜杠**：`https://chat.example.net`
- 双域并存时：建议入口、落地都填备用域（用户始终落到备用）
- 全面切换时：两处都必须是备用域，避免跳回已被屏蔽的主域
- 保存后，到「接入方法」重新点一次「生成 js / 生成链接」，不要继续复制旧代码

## 4. 修改项目根目录 `.env`（推送与站点域名）

文件位置（与 `application` 同级）：

```text
/www/wwwroot/你的项目/.env
```

### 4.1 模式 A：双域并存（推送仍跟「用户打开的页」走）

若用户主要打开备用域对话页，建议 `.env` 里推送主机也改成备用域（避免 https 页连旧域 wss 被拦）：

```ini
APP_DOMAIN = "https://备用域名"

PUSHER_AHOST = "http://127.0.0.1"
PUSHER_APORT = "2082"

; ---- 方案 A：开放 2081 ----
PUSHER_WHOST = "wss://备用域名"
PUSHER_WPORT = "2081"
PUSHER_SSL_CERT = "/www/server/panel/vhost/cert/备用域名/fullchain.pem"
PUSHER_SSL_PK = "/www/server/panel/vhost/cert/备用域名/privkey.pem"
```

证书路径以宝塔「网站 → 备用域名 → SSL」实际目录为准。

### 4.2 方案 B：推送走子域 443（可不对公网开 2081）

1. 解析并添加站点 `ws.备用域名`，开 SSL  
2. 反代到 `http://127.0.0.1:2081`（见 `安装说明.md`）  
3. `.env`：

```ini
APP_DOMAIN = "https://备用域名"
PUSHER_WHOST = "wss://ws.备用域名"
PUSHER_WPORT = "443"
PUSHER_AHOST = "http://127.0.0.1"
PUSHER_APORT = "2082"
PUSHER_SSL_CERT = ""
PUSHER_SSL_PK = ""
```

### 4.3 改完 `.env` 必须重启推送

```bash
cd /www/wwwroot/你的项目/ymwl_pusher
/www/server/php/74/bin/php start.php restart
/www/server/php/74/bin/php start.php status
```

用 Supervisor 时，在面板里重启 `ymwl_pusher` 进程。

## 5. 接入链接全集（把域名换成备用即可）

以下 `商户ID` 换成你的 `business_id`。

### 5.1 通用访客（网页 / 短信 / 二维码）

```text
https://备用域名/index/index/home?business_id=商户ID
```

### 5.2 指定技能组

```text
https://备用域名/index/index/home?business_id=商户ID&groupid=分组ID
```

### 5.3 指定客服（专属）

```text
https://备用域名/index/index/home?business_id=商户ID&groupid=0&special=客服service_id
```

也可在后台「接入方法 → 生成我的专属链接 / 微信公众号链接」重新生成。

### 5.4 手机端

```text
https://备用域名/mobile/index/home?business_id=商户ID&visiter_id=用户ID
```

### 5.5 App 带资料（敏感字段必须签名）

```text
https://备用域名/index/index/home?business_id=商户ID&visiter_id=APP用户ID&visiter_name=昵称&avatar=头像URL&email=a@b.com&real_name=真实姓名&id_card=证件号&phone=手机号&timestamp=Unix时间戳&sign=签名
```

```text
sign = md5(business_id + '#' + visiter_id + '#' + timestamp + '#' + app_secret)
```

- `timestamp` 有效约 5 分钟  
- **无签名时**只能传昵称/头像等展示字段，不能传邮箱/实名/证件/手机  

### 5.6 服务端同步 API

```http
POST https://备用域名/api/user/sync
Content-Type: application/json
```

鉴权二选一：请求体 `timestamp+sign`，或头 `X-Api-Token: 你的API_ACCESS_TOKEN`。

### 5.7 网站嵌入 JS / 弹窗 / 悬浮

1. 用备用域打开客服后台（或确保「入口域名」已是备用域）  
2. **接入方法** → 重新点「生成 js / 弹窗 / 悬浮 / html」  
3. 把新代码贴到网站（替换旧主域脚本）  
4. 全局搜索网站源码里的旧域名 `主域名`，全部换成 `备用域名`

手写时，所有：

```text
https://主域名/...
```

改为：

```text
https://备用域名/...
```

### 5.8 后台自己登录（可主可备）

```text
https://备用域名/admin
https://备用域名/platform
```

主域没被拦时，管理员仍可用主域登录。

## 6. App / 投放侧怎么改

| 位置 | 改法 |
|------|------|
| App 内打开客服 WebView 的 URL | 换成 5.1 / 5.5 备用域链接 |
| App 配置中心 / 热更新配置 | 客服 baseUrl 改为 `https://备用域名` |
| 同步资料接口 | `https://备用域名/api/user/sync` |
| 短信 / 邮件 / 海报二维码 | 重新生成指向备用域 |
| 公众号菜单 / 自动回复 | 链接改为备用域；公众号后台「业务域名」加入备用域 |
| 广告投放落地页 | 落地 URL 改为备用域 |

**建议：** App 不要写死域名，用服务端下发 `kefu_base_url`，被拦时只改配置不用发版。

## 7. 推荐切换顺序（按这个做不易乱）

```
① 备用域解析生效
② 宝塔添加站点（同 public）+ SSL + 伪静态
③ 浏览器打开 https://备用域名 确认正常
④ 客服后台：入口域名、落地域名改为 https://备用域名（无末尾/）
⑤ 改 .env：APP_DOMAIN + PUSHER_WHOST（及方案 A 证书路径）
⑥ 重启 ymwl_pusher
⑦ 接入方法重新生成 js/链接；App/投放替换旧链接
⑧ 自检：访客进线、实时消息、App 同步
⑨ 主域仅留作后台备用或停用对外投放
```

## 8. 切换后自检清单

- [ ] `https://备用域名` 首页 200，证书正常  
- [ ] `https://备用域名/index/index/home?business_id=商户ID` 能进聊天  
- [ ] 访客发消息，客服实时收到（pusher status 正常）  
- [ ] 方案 A：`2081` 已放行且证书路径存在；或方案 B：`wss://ws.备用域名` 可连  
- [ ] 客服后台「接入方法」里生成的链接已是备用域  
- [ ] App / 网站 / 二维码不再指向被屏蔽的主域  
- [ ] `.env` 里 `PUSHER_AHOST` 仍是 `http://127.0.0.1`  
- [ ] 登录后台改过默认密码；`安装.php` 已删除或锁定  

快速命令：

```bash
cd /www/wwwroot/你的项目/ymwl_pusher
/www/server/php/74/bin/php doctor.php
/www/server/php/74/bin/php start.php status
```

## 9. 回滚（备用域也有问题或要改回主域）

1. 客服后台入口/落地域改回 `https://主域名`  
2. `.env` 的 `APP_DOMAIN`、`PUSHER_WHOST`、证书路径改回主域  
3. `php start.php restart`  
4. App/投放链接改回主域（或再换第三域）  

数据在同一数据库，**切换域名不会丢聊天记录**。

## 10. 常见问题

**1）打开备用域又跳回主域**  
落地域名 `domain_landing` 仍是主域，或手机端检测到 host 不一致在跳转。两处都改成备用域。

**2）页面能开，消息不实时**  
推送没 restart；`PUSHER_WHOST` 仍是旧域；方案 A 证书还是主域路径；或 https 页连了错误的 wss。

**3）微信里打不开**  
确认备用域 HTTPS 正常；公众号业务域名已加备用域；尽量不用 IP；可再换更新域名。

**4）嵌入 JS 还是旧域**  
必须重新生成并替换页面里的旧脚本；清 CDN/浏览器缓存。

**5）API 同步失败**  
URL 已换备用域；签名用的仍是同一套 `app_secret`；服务器时间准确。

**6）两个宝塔站点会不会冲突**  
不会，只要根目录都指向同一个 `public`，只是两个 server_name。

## 11. 可直接替换的模板（复制改三处）

假设：备用域 `chat.example.net`，商户 `1`。

**.env（方案 A）**

```ini
APP_DOMAIN = "https://chat.example.net"
PUSHER_WHOST = "wss://chat.example.net"
PUSHER_WPORT = "2081"
PUSHER_AHOST = "http://127.0.0.1"
PUSHER_APORT = "2082"
PUSHER_SSL_CERT = "/www/server/panel/vhost/cert/chat.example.net/fullchain.pem"
PUSHER_SSL_PK = "/www/server/panel/vhost/cert/chat.example.net/privkey.pem"
```

**后台入口 / 落地**

```text
https://chat.example.net
```

**常用链接**

```text
https://chat.example.net/index/index/home?business_id=1
https://chat.example.net/admin
https://chat.example.net/platform
POST https://chat.example.net/api/user/sync
```
