# 宝塔部署 — 推荐配置顺序（按这个做不会乱）

> 完整说明：`install/安装说明.md`  
> 下面是**从零到能聊**的固定顺序；不要跳步（尤其是先起 pusher 再改证书）。

---

## 一、一次性准备（软件环境）

1. 宝塔安装：**Nginx** + **MySQL 5.7/8.0** + **PHP 7.4**（不要 PHP 8）
2. PHP 扩展：`/www/server/php/74/bin/php -m` 核对；推送必有 **`pcntl`**
3. PHP「禁用函数」只保留安装说明 1.3 那一行；**不要**禁用 `putenv`、`pcntl_*`
4. 调整：`memory_limit=256M`、`upload_max_filesize=50M`、时区 `Asia/Shanghai`

---

## 二、代码与网站

5. 源码放到 `/www/wwwroot/你的域名/`
6. 宝塔添加网站：**根目录 =** `/www/wwwroot/你的域名/public`，PHP 7.4
7. 伪静态 / 禁止访问 `runtime`、`application` 等（见安装说明）
8. **删除** `install/install.lock`（仓库自带，不删无法网页安装）

```bash
rm -f /www/wwwroot/你的域名/install/install.lock
```

---

## 三、数据库与安装

### 推荐：网页安装

9. 浏览器打开 `https://你的域名/安装.php`  
10. 填域名（`https://你的域名`）、库账号、平台管理员、客服管理员 → 安装  
11. 向导会自动写根目录 `.env`、导入 `data.sql`、建账号  

### 或手动

9. 建库（utf8mb4），导入 `install/data.sql`  
10. `cp .env.example .env`，按下方模板填写  

---

## 四、核对 / 补全 `.env`

12. 确认文件在：`/www/wwwroot/你的域名/.env`（不要放 `public/`）  
13. 主站先开好 HTTPS  
14. 按方案 A 或 B 补全 Pusher（见下方完整模板）  
15. 保存后**再**启动 / 重启 pusher  

---

## 五、实时消息通道（二选一）

### 方案 A（开放 2081，证书给 pusher）— 推荐先试

| 顺序 | 操作 |
|------|------|
| A1 | 云安全组 + 宝塔防火墙 **放行 TCP 2081** |
| A2 | `.env` 写好 `PUSHER_WHOST` / `PUSHER_WPORT=2081` |
| A3 | `.env` **一并添加** `PUSHER_SSL_CERT` / `PUSHER_SSL_PK` |
| A4 | 确认证书文件存在（宝塔「网站 → SSL」可看路径） |
| A5 | 再启动 / 重启 `ymwl_pusher` |

证书路径示例（域名换成你的）：

```text
/www/server/panel/vhost/cert/你的域名/fullchain.pem
/www/server/panel/vhost/cert/你的域名/privkey.pem
```

### 方案 B（子域名反代，走 443）

| 顺序 | 操作 |
|------|------|
| B1 | 解析 `ws.你的域名` → 服务器 IP |
| B2 | 宝塔新建站点 `ws.你的域名`，开 SSL |
| B3 | 反代到 `127.0.0.1:2081`（安装说明 6 节） |
| B4 | `.env`：`PUSHER_WHOST=wss://ws.你的域名`，`PUSHER_WPORT=443` |
| B5 | **不要**填 `PUSHER_SSL_*` |
| B6 | 启动 / 重启 `ymwl_pusher` |

## 六、启动推送进程

```bash
cd /www/wwwroot/你的域名/ymwl_pusher
/www/server/php/74/bin/php doctor.php
/www/server/php/74/bin/php start.php start -d
/www/server/php/74/bin/php start.php status
```

Supervisor 守护：启动命令用同一 `php .../start.php start`（一般不加 `-d`）。  
以后改 `.env` 或证书：

```bash
/www/server/php/74/bin/php start.php restart
```

---

## 七、收尾

16. 打开 `https://你的域名`，进登录页  
17. 改平台 / 客服密码；改网站名 / Logo  
18. 建议确认 `.env` 里已有 `API_ACCESS_TOKEN`  
19. 删除或改名 `public/安装.php`  
20. 测访客发消息是否实时  

---

> `.env` 用 `parse_ini_file` 风格：**注释用 `;`，带 `://` 的值必须双引号**。

## 方案 A：`.env` 完整模板

```ini
DB_HOST = "127.0.0.1"
DB_PORT = "3306"
DB_DATABASE = "你的库名"
DB_USERNAME = "你的用户"
DB_PASSWORD = "你的密码"

APP_DOMAIN = "https://你的域名"

PUSHER_APP_KEY = ""
PUSHER_APP_SECRET = ""
PUSHER_APP_ID = "232"
PUSHER_WHOST = "wss://你的域名"
PUSHER_WPORT = "2081"
PUSHER_AHOST = "http://127.0.0.1"
PUSHER_APORT = "2082"

; 方案 A 必须写（https 页面要用 wss）
PUSHER_SSL_CERT = "/www/server/panel/vhost/cert/你的域名/fullchain.pem"
PUSHER_SSL_PK = "/www/server/panel/vhost/cert/你的域名/privkey.pem"

YMWL_SALT = ""
REGIST_TOKEN = ""
API_ACCESS_TOKEN = ""
```

## 方案 B：`.env` 完整模板

```ini
DB_HOST = "127.0.0.1"
DB_PORT = "3306"
DB_DATABASE = "你的库名"
DB_USERNAME = "你的用户"
DB_PASSWORD = "你的密码"

APP_DOMAIN = "https://你的域名"

PUSHER_APP_KEY = ""
PUSHER_APP_SECRET = ""
PUSHER_APP_ID = "232"
PUSHER_WHOST = "wss://ws.你的域名"
PUSHER_WPORT = "443"
PUSHER_AHOST = "http://127.0.0.1"
PUSHER_APORT = "2082"

PUSHER_SSL_CERT = ""
PUSHER_SSL_PK = ""

YMWL_SALT = ""
REGIST_TOKEN = ""
API_ACCESS_TOKEN = ""
```

## 常见卡点

1. `.env` 不在根目录 / 写成 `.env.txt`  
2. 方案 A 忘写证书或路径错 → 进程退出  
3. 方案 A 没放行 2081  
4. 改完 `.env` 没 restart  
5. 网站根目录指到项目根而不是 `public/`  
6. PHP 8，或禁用了 `pcntl_*` / `putenv`  
7. 没删 `install.lock` → 无法网页安装  
8. 没装 **pcntl** → `status` 一直 `not run`

### `status` 一直 `not run`

```bash
cd /www/wwwroot/你的域名/ymwl_pusher
/www/server/php/74/bin/php doctor.php
/www/server/php/74/bin/php -m | grep -E 'pcntl|posix'
/www/server/php/74/bin/php -r 'echo ini_get("disable_functions"), "\n";'
# 前台启动看真实报错（不要加 -d）
/www/server/php/74/bin/php start.php start
```
