## 1. 环境与版本要求

### 1.1 推荐组合（宝塔）

| 组件 | 推荐版本 | 说明 |
|------|----------|------|
| 系统 | CentOS 7+ / Ubuntu 20+ / Debian 11+ | 64 位 |
| 面板 | 宝塔 Linux 面板 | 官方版即可 |
| Web | **Nginx 1.20+** | 推荐；Apache 亦可，反代 WS 更麻烦 |
| PHP | **7.4**（首选） | ThinkPHP **5.0.24**；7.3 可用；**不要用 PHP 8.x** |
| 数据库 | **MySQL 5.7** 或 **MySQL 8.0** | 字符集 **utf8mb4**；MariaDB 10.3+ 也可；`data.sql` 已用 `ROW_FORMAT=Dynamic` 兼容 MySQL 8 |
| 内存 | ≥ 2GB | 建议 4GB+（pusher + PHP-FPM） |
| 磁盘 | ≥ 20GB | 含日志、上传、备份 |

### 1.2 PHP 扩展

宝塔「安装扩展」列表**不会列出全部扩展**。以内置命令为准：

```bash
/www/server/php/74/bin/php -m
```

| 扩展 | 重要性 | 说明 |
|------|--------|------|
| `curl` | 必有 | 一般已带 |
| `pdo_mysql` / `mysqli` | 必有 | 连库 |
| `mbstring` | 必有 | 字符串 |
| `openssl` | 必有 | 多数内置，列表可能没有 |
| `fileinfo` | 建议 | 上传类型 |
| `gd` | 建议 | 验证码/图片 |
| `opcache` | 建议 | 提速 |
| **`pcntl`** | **推送必有** | 列表里有就装 |
| `posix` | 推送需要 | 多数内置；用 `php -m` 确认 |

装法：软件商店 → PHP-7.4 → 设置 → **安装扩展** → 只装缺的 → 重载配置。

### 1.3 PHP 禁用函数（重要）

宝塔 → PHP-7.4 → 设置 → **禁用函数** → **清空后只粘贴下面一行**，保存并重载：

```
passthru,exec,system,chroot,chgrp,chown,shell_exec,popen,proc_open,proc_get_status,proc_close,proc_terminate,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru,imap_open,apache_setenv
```

- **不要**禁用 `putenv`、任何 `pcntl_*`（pusher / Workerman 需要）。
- 若报 `putenv() has been disabled`：禁用列表里还有 `putenv`，删掉后重载再启 pusher。

### 1.4 PHP 其它配置

| 配置项 | 建议值 |
|--------|--------|
| `memory_limit` | `256M`+ |
| `max_execution_time` | `300` |
| `max_input_time` | `300` |
| `post_max_size` | `50M` |
| `upload_max_filesize` | `50M` |
| `date.timezone` | `Asia/Shanghai` |

## 3. 获取代码并创建网站

### 3.1 上传代码

```bash
cd /www/wwwroot
git clone https://github.com/Axuhan7/Kkf.git 你的域名
# 或上传 zip / rar 解压到 /www/wwwroot/你的域名/
```

项目根应含：`public/`、`application/`、`install/`、`ymwl_pusher/`、`.env.example`。

多数发行包已带 `vendor/`；若缺：

```bash
cd /www/wwwroot/你的域名
composer install --no-dev
```

### 3.2 添加站点（关键）

1. **网站 → 添加站点**  
2. 域名填你的域名  
3. **根目录必须：**

```text
/www/wwwroot/你的域名/public
```

4. PHP 选 **7.4**；可同时创建数据库（utf8mb4），记下库名/用户/密码  
5. **站点设置 → SSL** 申请 Let’s Encrypt，开启强制 HTTPS  

### 3.3 伪静态

可用「thinkphp」规则，或：

```nginx
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=$1 last;
        break;
    }
}
```

建议额外禁止访问源码目录：

```nginx
location ~* ^/(runtime|application|config|install|vendor|thinkphp)/ {
    deny all;
}
```

### 3.4 目录权限

```bash
cd /www/wwwroot/你的域名
chmod -R 755 runtime public/upload public/uploads 2>/dev/null
mkdir -p runtime public/upload public/uploads
chown -R www:www runtime public/upload public/uploads
```

### 3.5 允许重新安装（仓库自带锁文件）

本仓库含 `install/install.lock`。**全新安装前必须删除：**

```bash
rm -f /www/wwwroot/你的域名/install/install.lock
```

否则访问 `/安装.php` 会提示「系统已安装」。

## 4. 数据库与安装方式（二选一）

### 方式一：网页安装向导（推荐新手）

1. 浏览器打开：`https://你的域名/安装.php`  
2. 填写：站点域名（`https://你的域名`，无末尾斜杠）、数据库账号、平台管理员、客服管理员  
3. 向导会：导入 `install/data.sql`、创建账号、**写入项目根目录 `.env`**、尝试启动 pusher、创建 `install.lock`  
4. 安装成功后建议删除或改名：`public/安装.php`  

> 加固版安装器**不会**把库密码硬写进 `config/database.php`，一律走 `.env`。

### 方式二：手动导入 + `.env`

1. 宝塔数据库 → 导入 `install/data.sql`  
2. 项目根目录：

```bash
cd /www/wwwroot/你的域名
cp .env.example .env
chmod 600 .env
# 编辑 .env 填库名、密码、域名、Pusher
```

3. 自行创建管理员：仍可用网页向导（需先删 lock），或按系统规则写入 `wolive_admin` / `wolive_service`。

### 演示库（一般不推荐新装）

若必须用演示数据：解压根目录 `数据库.sql.zip` 或导入 `install/demo_dump_sanitized.sql`。  
演示平台管理员密码已重置为 `ChangeMe123`，**登录后立刻修改**。

### SQL 文件一览

| 文件 | 用途 |
|------|------|
| `install/data.sql` | **新装唯一必需** |
| `install/demo_dump_sanitized.sql` | 已清洗演示库（可选） |
| `install/update_ai.sql` | 老库补 AI（可选） |

## 5. 配置 `.env`

位置：**项目根目录**（与 `application/` 同级），**不要**放进 `public/`。

规则：

- 注释用 `;`（不要用带 `=` 的乱行）  
- 含 `://` 的值必须加双引号  
- 改完后重启 pusher  

最少字段见 `.env.example`。完整方案 A/B 模板见 [`配置顺序.md`](配置顺序.md)。

| 配置 | 谁用 | 含义 |
|------|------|------|
| `PUSHER_WHOST` + `PUSHER_WPORT` | 浏览器 | WebSocket 主机+端口 |
| `PUSHER_AHOST` + `PUSHER_APORT` | PHP | 本机推送 API，一般 `http://127.0.0.1:2082` |
| `PUSHER_SSL_CERT` / `PUSHER_SSL_PK` | 方案 A | 宝塔证书路径 |

**方案 A（最简单）：** 放行 2081 + 主站证书路径写进 `.env` + 重启 pusher。  
**方案 B：** `ws.域名` Nginx 反代到 `127.0.0.1:2081`，`WPORT=443`，SSL 两行留空。

密钥留空时会写入 `runtime/local_secrets.php`（勿提交 Git）；Web 与 pusher 必须同一套。

## 6. Nginx 与方案 B 反代

主站根目录 `.../public`，PHP 用 `enable-php-74.conf`（以面板为准）。

方案 B 站点 `ws.你的域名`：

```nginx
location / {
    proxy_pass http://127.0.0.1:2081;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
}
```

## 11. 常见问题

1. **pusher `not run`**：跑 `doctor.php`；前台 `php start.php start` 看报错；查 pcntl / 禁用函数 / 证书路径。  
2. **能开后台不实时**：pusher、密钥是否一致、2081/证书或反代。  
3. **https 下 WS 失败**：必须 `wss`；方案 A 要 `PUSHER_SSL_*`。  
4. **`.env syntax error`**：URL 加双引号；注释用 `;`。  
5. **putenv disabled**：禁用列表去掉 `putenv`（加固版也兼容禁用，但仍建议放开）。  
6. **PHP 8 报错**：改回 7.4。  
7. **上传 413**：提高 PHP 与 Nginx `client_max_body_size`。  
8. **提示已安装**：删除 `install/install.lock`。

## 12. 安全建议

1. 面板 / SSH / 库用强密码，限制 IP  
2. 配置 `API_ACCESS_TOKEN`、盐值、Pusher 密钥  
3. `app_debug=false`  
4. 定期备份数据库与 `public/upload`  
5. 勿提交 `.env`、`runtime/local_secrets.php`  
6. 2082 不对公网开放  
7. 装完删除 `public/安装.php`
